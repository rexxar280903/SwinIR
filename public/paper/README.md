# Paper publik

`paper_ieee_id.html` berasal dari naskah hasil aktual tanggal 11 Oktober 2026. Gambar contoh wajah dihapus dari salinan publik karena hak redistribusi belum terverifikasi. Grafik sweep dan validasi merupakan visualisasi angka eksperimen dan tetap disertakan. Versi lengkap lokal tidak diubah.

Sitasi bernomor [1]–[12] dalam naskah merujuk sumber primer untuk SwinIR, Swin Transformer, loss restorasi, supervisi gradien, SSIM, GMSD, dataset, Adam, bootstrap, Wilcoxon, dan Holm. Setiap entri memiliki tautan sumber. Rekaman publikasi dan metadata bibliografi diperiksa; beberapa laman penerbit hanya memberikan wrapper atau menolak pengambilan penuh. Rumus lokal serta variasi implementasi metrik dijelaskan terpisah dari publikasi rujukan.

Layout mengadaptasi [panduan konferensi IEEE](https://conferences.ieeeauthorcenter.ieee.org/write-your-paper/authoring-tools-and-templates/) untuk HTML. Pengiriman akhir memerlukan template Word/LaTeX serta batas halaman konferensi tujuan. Kolom identitas bisa diedit di browser; penyimpanan tersebut lokal pada browser dan tidak menulis ulang berkas sumber.
